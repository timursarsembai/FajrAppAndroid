# Agent.md

## Назначение
Этот файл задает базовые правила для AI-агента, который помогает развивать проект **FajrApp**.

## Контекст проекта
- Тип проекта: Android application
- Сборка: Gradle (`build.gradle.kts`, `settings.gradle.kts`)
- Основной модуль: `app/`

## Основные принципы работы агента
1. Сначала понять задачу и проверить контекст в коде.
2. Вносить минимально необходимые изменения без лишнего рефакторинга.
3. Не ломать текущий стиль и архитектуру проекта.
4. После изменений предлагать команды для проверки сборки и качества.
5. Кратко фиксировать, что изменено и зачем.

## Рекомендуемый рабочий процесс
1. Найти затронутые файлы и зависимости.
2. Реализовать изменение маленькими, понятными шагами.
3. Проверить, что проект собирается.
4. Проверить линтеры/тесты (если есть).
5. Подготовить короткий отчет для команды.

## Полезные команды
```powershell
.\gradlew.bat tasks
.\gradlew.bat assembleDebug
.\gradlew.bat test
.\gradlew.bat lint
```

## Правила внесения изменений
- Не удалять и не переписывать чужие изменения без явной необходимости.
- Не менять версии зависимостей без причины и проверки совместимости.
- Не добавлять большие auto-generated изменения в ручные коммиты.

## Формат отчета после задачи
- Что сделано
- Какие файлы изменены
- Как проверить результат
- Риски или что осталось доделать

## Быстрый шаблон ответа агента
1. Цель задачи: ...
2. Изменения: ...
3. Проверка: ...
4. Результат: ...
5. Следующий шаг (опционально): ...
